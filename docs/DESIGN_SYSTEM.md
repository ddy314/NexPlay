# NexPlay Navigation Language

NexPlay 的界面不是网页卡片集合，而是一套面向桌面媒体体验的二维导航系统。设计目标是：用户只看图形、位置和短标签，也能知道“我在哪里、下一步去哪、内容现在是什么状态”。

## 1. 原则

1. **重平面**：使用有明确边界和功能的实色平面。模糊只属于导航、浮层和播放器控制层，不作为普通卡片背景。
2. **重图示**：状态优先用图形、进度、位置、颜色和数值表达；说明文字只补充无法由图形表达的信息。
3. **大小拼接**：页面使用 12 列栅格和 16px 沟槽。特征面板必须与普通信息块形成大小层级，避免全页同尺寸卡片。
4. **机场导视**：主区域使用稳定编号、方向符号、简短动词和颜色分区。导航标签不写技术实现名称。
5. **内容优先**：海报、视频与洞察图形是主角。装饰色不得压过内容，取色不得改变全局可读性。
6. **Apple HIG**：直接、可预期、可撤销；主要操作至少 44px；键盘、鼠标、深色主题和 reduced motion 都是基础能力。

## 2. 信息架构

顶层只有五区：`首页 / 发现 / 媒体库 / 下载 / 洞察`。搜索是全局覆盖层，设置位于导航底部。

- 首页：回答“现在看什么”。
- 发现：回答“已有收藏之外还有什么”。
- 媒体库：回答“我拥有什么以及如何组织”。
- 下载：回答“内容获取到哪一步”。
- 洞察：回答“我的观看节奏发生了什么”。
- 详情、资源和播放器属于内容栈，不是新的顶层区域。

## 3. Tokens

唯一实现入口为 `frontend/src/design-system.css`。组件不得自行定义另一套主题变量。

- 间距：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 字号：`11 / 13 / 15 / 17 / 22 / 28 / 34`。
- 图标：`16 / 20 / 24 / 32`；普通线宽保持 1.8–2。
- 圆角：控件 12px、内容卡 18px、特征平面 24px。
- 控件高度：主要交互不低于 44px。
- 表面：背景、一级平面、二级平面、三级平面、浮层五级，不通过任意透明白色制造层级。

原始十六进制颜色只允许出现在 token、数据图颜色和内容取色逻辑。产品组件使用语义变量 `--nx-*`。禁止在页面组件中新增 `dark:` 补丁链。

## 4. 组件语言

- `Plane`：承载一个完整任务或信息结论，允许 feature/standard/compact 三档。
- `Mosaic`：12 列拼接容器；同一屏至少存在两种组件尺寸。
- `Wayfinding label`：图标 + 10–11px 大写短标签，用于区域定位，不承载正文。
- `Media tile`：poster/wide/hero 三种；标题只出现一次，推荐原因在需要时显示。
- `Metric / Figure`：必须先给结论，再给图。图表必须有可理解的数值或比例语义。
- `List row`：左图示、中内容、右状态/方向。整行可点击时不再嵌套重复主按钮。
- `Empty state`：说明当前状态、为什么为空、唯一下一步；不得只写“暂无数据”。
- `Popover / Drawer`：临时任务使用浮层；选集、字幕、音轨和下载文件选择不得永久挤压主内容。

## 5. 动效

- 控件反馈 140–180ms，页面/抽屉 180–220ms。
- 顶层切换轻交叉淡化；详情按栈方向推进；播放器从内容上方呈现。
- 只动画 `transform` 与 `opacity`。禁止大面积弹跳、长列表逐项错峰和无语义缩放。
- 播放器控制层在播放中闲置约 2 秒隐藏；暂停状态只显示暂停标识。
- `prefers-reduced-motion` 或用户设置开启后，空间位移和缩放必须消失。

## 6. 深色模式与无障碍

- 主题必须设置在 `document.documentElement`，确保 body、Portal、滚动条和原生表单继承。
- 深色模式使用黑色背景、1C/2C/3A 灰阶平面；不能把浅色界面整体降低亮度。
- 正文对比度至少 4.5:1，状态不得只依赖颜色。
- 所有图标按钮必须有 `aria-label`；完整流程必须能用键盘完成。
- 焦点状态必须可见。播放器快捷键不得覆盖文本输入。

## 7. 提交前检查

- 页面是否只回答一个主要问题？
- 是否存在可以用图形、进度或位置替代的长文字？
- 同屏组件是否形成大小层级，而不是均匀白卡？
- 深色主题下 body、Dialog、Popover、Toast 是否都正确？
- 页面切换后返回，滚动、筛选和播放状态是否保留？
- 播放器改动是否仍经过既有 seek、WebGL、字幕记忆和弹幕 reset 路径？
- 空、少量、大量、错误和离线数据是否都有完整状态？
